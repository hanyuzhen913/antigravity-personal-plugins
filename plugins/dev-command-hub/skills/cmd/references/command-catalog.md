# Dev Command Hub — 全量指令与意图路由手册

本手册收录 **3 套组合工作流** 与 **24 条官方核心指令**，并标注适用端与配额提醒。

---

## 一、三套高频组合工作流

| 短指令 | 工作流名称 | 编排链路 | 适用端 |
| :--- | :--- | :--- | :--- |
| **`/nf`** | 新功能标准流 | `/grill-me`（对齐需求）→ `/plan`（出方案）→ 确认实施 → 提醒 `/learn`（沉淀） | 通用 |
| **`/dbg`** | 硬核排障流 | `/diff` + `/codesearch`（查改动与检索）→ 疑难升级 `/boost` → 前端联动 `/browser` | 通用（部分步骤 CLI/付费增强） |
| **`/ctx`** | 长对话减负流 | 查上下文占用（CLI `/context` / App 面板）→ `/compact` 压缩检查点 → 提炼决策 | App / CLI |
| **`/hub`** | 可视化指令控制台 | 按 `generative_ui` 在侧边栏打开 macOS 毛玻璃指令中心 | 仅 App（CLI 降级为 `/cmd`） |
| **`/cmd`** | 中文智能路由与速查 | 中文大白话匹配并执行/推荐对应指令 | 通用 |

## 二、24 条全量官方指令清单

### 1. 需求与执行
- **`/grill-me [task]`** `[通用]`：动工前逐条反问对齐需求，并给出每题推荐答案。
- **`/plan [task]`** `[通用]`：只读探索代码库并输出可审阅的实施计划，确认前不改代码。可与 `/grill-me` 联用：`/plan /grill-me <任务>`。
- **`/goal <objective>`** `[通用]`：设定明确验收目标，自主闭环迭代验证直至完成，不中途频繁打断。
- **`/schedule <when> <task>`** `[通用]`：在当前会话内设置单次定时提醒或 Cron 周期巡检。
- **`/automation [prompt]`** `[仅 App]`：引导创建独立后台定时自动化任务（在 Automations 标签页管理）。

### 2. 多智能体攻坚（⚠️ 高配额提醒）
- **`/boost <task>`** `[通用]` `⚠️ 高配额・付费`：启动多代理深度推理流水线，专攻疑难 Bug、竞态条件与复杂算法。
- **`/swarm <task>`** `[App / CLI]` `⚠️ 高配额`：拆分子任务给多个命名工人并行开发，并由 `@verifier` 在共享看板协同验收（CLI 可用 `Alt+S` 或 `/swarm board` 看看板）。
- **`/teamwork <task>`** `[通用]` `⚠️ 高配额・付费`：启动长期协作型多代理团队，适合跨多天大型项目、框架迁移与深度研究。

### 3. 调试与可视化
- **`/browser <task>`** `[通用]`：委托内置浏览器子代理执行页面操作、截图、控制台检查与前端视觉验收。
- **`/generative_ui <prompt>`** `[仅 App]`：在侧边栏或对话中渲染交互式 HTML 图表、流程图与控件。
- **`/codesearch <query>`**（别名 `/cs`, `/search`）`[仅 CLI]`：不离开当前会话打开交互式全库代码搜索面板。
- **`/diff`** `[仅 CLI]`：打开交互式 Diff 面板查看当前改动、对话轮次变更与 Git 提交。

### 4. 上下文与会话控制
- **`/btw <query>`** `[通用]`：在只读旁支中快速提问，不打断主任务也不污染主对话历史。
- **`/compact [message]`** `[App / CLI]`：将对话摘要为压缩检查点释放上下文空间，并可附带下一步指令继续执行。
- **`/context`** `[仅 CLI]`：打开上下文窗口 Token 占比可视化面板。
- **`/fork`**（别名 `/branch`）`[仅 CLI]`：克隆当前对话分支出一条平行会话用于安全试错。
- **`/rewind`**（别名 `/undo`）`[仅 CLI]`：将对话历史回退到之前的某条消息检查点。
- **`/clear`**（别名 `/new`）`[仅 CLI]`：清空终端屏幕并重置当前对话上下文。

### 5. 定制与工程工具
- **`/learn [instruction]`** `[通用]`：把当前会话中的纠错、踩坑或规范提炼为可审阅提案，沉淀为持久化规则或技能。
- **`/agy-customizations [request]`** `[通用]`：载入官方定制系统参考，辅助创建/修复规则、技能、插件、钩子与 MCP。
- **`/run-workflow <task>`** `[App / CLI]` `⚠️ 高配额`：编写并执行 Python 动态工作流脚本，以 `parallel()` / `pipeline()` 编排多代理。
- **`/mcp`** `[仅 CLI]`：打开 MCP 服务器管理面板。
- **`/skills reload`** `[仅 CLI]`：打开已加载技能列表（`/skills`）或从磁盘热重载技能（`/skills reload`）。
- **`/antigravity-guide [question]`** `[App / CLI]`：检索官方最新文档解答 Antigravity 使用与配置问题。

## 三、中文大白话映射参考

| 用户口语 | 映射指令 / 组合流 | 说明 |
| :--- | :--- | :--- |
| 打开指令面板 / 看看有哪些指令 | `/hub` | 仅 App 渲染交互卡片；CLI 用 `/cmd` |
| 别急着写，先问清楚需求 | `/grill-me` | 逐条反问对齐 |
| 先出个方案看看 | `/plan` | 先出计划，确认再写 |
| 自己跑通测试别老停下来问 | `/goal` | 自主闭环到验收通过 |
| 做个新功能（完整流程） | `/nf` | 对齐 → 方案 → 执行 → 沉淀 |
| 帮我系统排障 / 查顽固 Bug | `/dbg` | Diff + 搜索 → `/boost` → `/browser` |
| 拆成几个模块同时写 / 多人并行 | `/swarm` | ⚠️ 高配额 |
| 太难了 / 并发竞态深挖一下 | `/boost` | ⚠️ 高配额・付费 |
| 顺便问个无关问题 | `/btw` | 旁支只读提问 |
| 太长了整理下记忆 / 减负 | `/ctx` / `/compact` | 检查占用并压缩检查点 |
| 把这次踩的坑记下来 | `/learn` | 沉淀为规则或技能 |
| 查改动 / 搜全库 / 回退 / 分叉 | `/diff` / `/cs` / `/rewind` / `/fork` | 均标注 `[仅 CLI]` |
