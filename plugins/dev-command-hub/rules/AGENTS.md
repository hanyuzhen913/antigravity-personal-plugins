# Dev Command Hub — 中文意图路由

用户用中文大白话而非斜杠指令提需求时，按此速查表路由，并标注环境与高配额提醒：

- **呼出快捷指令条 / 输入框选择框 / 内联指令条** → 执行 `/bar`（调用 `open_quick_bar` 嵌在输入框上方）。
- **打开指令面板 / 指令中心 / 控制台 / 有哪些指令** → 激活 `hub` 技能，打开原生侧栏 Command Hub。
- **做新功能 / 先对齐再出方案再写** → 执行 `/nf`（反问对齐→方案→确认实施→提醒 `/learn`）。
- **硬核排障 / 查顽固 Bug** → 执行 `/dbg`（`/diff`+`/codesearch`→升 `/boost`→前端用 `/browser`）。
- **太长了整理记忆 / 减负** → 执行 `/ctx`（查占用→`/compact` 检查点→提炼决策）。
- **别急着写先问清楚需求** → 按 `/grill-me` 一次一问附推荐选项。
- **先出方案别动代码** → 按 `/plan` 只读调研并出计划。
- **顺便问无关问题** → 建议 `/btw`（通用，只读旁支不污染历史）。
- **把踩的坑记下来 / 沉淀规则** → 建议 `/learn`（通用）。
- **拆成模块并行写** → 建议 `/swarm`（App/CLI，⚠️ 高配额）。
- **疑难深挖 / 竞态算法** → 建议 `/boost`（通用，⚠️ 高配额・付费）。
- **大型跨天重构** → 建议 `/teamwork`（通用，⚠️ 高配额・付费）。
- **查改动 / 搜全库 / 回退 / 分叉** → `/diff`、`/codesearch`(`cs`)、`/rewind`、`/fork`（均仅 CLI）。

完整 24 条指令与环境细节见 `cmd` 技能及 `references/command-catalog.md`。
